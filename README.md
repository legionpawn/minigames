# FiveM Minigames Practice

Standalone browser-playable practice suite for 23 FiveM skillcheck and hacking minigames (including Byte Labs and Big Daddy minigames).

## Included Minigames (23)

### Byte Labs (16)
- **Circle Progress** (Radial timing check 1–4)
- **Linear Progress** (Horizontal bar timing 1–4)
- **Key Circle** (Dual-hand simultaneous combinations)
- **Key Spam** (Rapid tap expansion)
- **Number Slide** (Fast slider precision)
- **Rapid Lines** (Multi-channel falling bar catch)
- **Circle Shake** (Rotational boundary catch)
- **Path Find** (Maze navigation)
- **Untangle** (Planar intersection untangling)
- **Lights Out** (Rotational toggle matrix)
- **Digit Dazzle** (Binary / hexadecimal sequence)
- **Word Wiz** (Word unscrambling)
- **Circle Sum** (Radial target sum)
- **Wave Match** (Frequency & amplitude tuning)
- **Mine Sweeper** (Memory grid avoidance)
- **Print Lock** (Biometric fingerprint slice alignment)

### Big Daddy / BD (7)
- **BD Lockpick** (Concentric rotating rings with colored slot & ball alignment)
- **BD Chopping (Alphabet)** (Sequential rapid letter tapping across Q, W, E, R, A, S, D)
- **BD PIN Cracker** (Mastermind-style numeric code deduction with color clues)
- **BD Roof Running** (Isometric 3D block cluster collapse puzzle)
- **BD Thermite / Mazer** (Maze Bank pipe cross-connector chain reaction hack)
- **BD Laptop Terminal** (Sequence shape & color memorization + terminal quiz)
- **BD Word Memory** (Verbal memory assessment testing Seen vs New words)
